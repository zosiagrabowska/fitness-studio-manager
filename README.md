# Fitness Studio Manager

Spring Boot web application for fitness studio management.

## Features

**Manager Panel:**
- Create and edit fitness classes
- Manage participant groups  
- Class scheduling

**Participant Panel:**
- View class schedule
- Online registration

## Tech Stack
- Spring Boot 3.5.4
- Spring Data JPA + Hibernate
- H2 Database
- Maven

## URLs: 
- Manager: http://localhost:8080
- Participants: http://localhost:8080/participants
